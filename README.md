# Parity · presentación web

La presentación reproduce las 15 páginas del PDF original como diapositivas de alta resolución y agrega controles de navegación. No requiere instalar dependencias ni conectarse a Internet.

## Abrir

Abrí `index.html` en un navegador moderno. Para servirla desde VS Code, también podés usar la extensión Live Server.

## Navegación

- Flechas izquierda y derecha, espacio o los botones laterales: diapositiva anterior o siguiente.
- `Inicio` y `Fin`: primera y última diapositiva.
- `I`: abrir el índice.
- `F`: alternar pantalla completa.
- En pantallas táctiles, deslizá horizontalmente sobre la diapositiva.
- El número de diapositiva se refleja en la dirección como `#slide-1`, etc.

El botón de descarga permite abrir o guardar el PDF original. Las imágenes de `slides/` mantienen el aspecto de cada página; la primera diapositiva usa el logo nuevo. El archivo `logo-parity.png` también se utiliza en el encabezado. La presentación funciona sin servicios externos.
